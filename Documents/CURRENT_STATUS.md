# CURRENT_STATUS

## 项目定位

`GitHub Star Show` 是一个把 GitHub Stars 转成可长期整理、可持续同步、可自托管维护的个人项目库的 Web 应用。

核心原则：

- GitHub 负责远端事实
- 本地数据库负责用户整理结果
- 默认以规则分类为主，AI 只做可选增强
